# v2 — The Daily Desk

A static snapshot of the SheLedTheWay redesign. It is served behind the board login at `/v2/`.

- No backend; approvals and edits are prototype interactions.
- Photographs are real archive/Commons images, duotoned and credited in `IMAGE-CREDITS.md` and in Studio → Facts → Photographs.
- The source lives in the main repo under `design/`; this folder is the deployable snapshot.

The route is `webapp/app.py` → `/v2/`; it does not affect the v1 board.
