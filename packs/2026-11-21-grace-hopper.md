## On-screen hook
What if a computer could take word instructions? Hopper built a translator.

## Voiceover
Philadelphia, 1952. Grace Hopper’s team at UNIVAC develops A-0, a compiler that translates mathematical code into machine instructions. The system reduces a task that had required programmers to enter low-level code manually. Hopper wants computers to serve business users, not only mathematicians. FLOW-MATIC accepts familiar English-like commands for data processing. That work helps shape COBOL, a language built by a team—not invented by Hopper alone. The goal is computing more people can use. It brings business data processing within reach. She led the way.
